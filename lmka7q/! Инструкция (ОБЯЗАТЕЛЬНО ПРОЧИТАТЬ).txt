BIOS-КОНФИГИ (SCEWIN)
Работает только на материнских платах с BIOS от AMI (Aptio). Если SCEWIN пишет "AMISCE is not supported on this system", ваша плата не подходит.

ПЕРЕД ЛЮБЫМИ ИЗМЕНЕНИЯМИ:
1. Сфотографируйте текущие настройки BIOS или сохраните профиль, если BIOS это умеет.
2. Нажмите Export NVRAM и сохраните получившийся nvram.txt в надёжное место. Это ваш бэкап: с ним можно вернуть всё как было.
3. Применяйте конфиги по одному, после каждого перезагружайтесь и проверяйте, что всё работает.
4. Если ПК не стартует: сбросьте BIOS (кнопка Clear CMOS на плате, перемычка CLR_CMOS или вынуть батарейку CR2032 на несколько минут при выключенном и обесточенном ПК). Пункт "Load Optimized Defaults" в меню BIOS работает, только если ПК вообще запускается.

Чтобы применить конфиг:
Открыть SCEWIN-GUI от имени администратора -> Export NVRAM -> Check Settings -> нажать на конфиг, который хотите применить -> Apply Changes -> Import NVRAM -> перезагрузить ПК

ВАЖНО (читать перед применением):
- DISABLE-SECURITY: отключает TPM, Secure Boot, DMA-защиту и защиту от выполнения данных. На Windows 11 это может привести к проблемам с загрузкой и обновлениями, а игры с античитами уровня ядра (Vanguard / Valorant, FACEIT, часть игр с Easy Anti-Cheat и BattlEye) откажутся запускаться. Не применяйте, если играете в такие игры. Конфиг снижает защиту компьютера от вредоносных программ.
- DISABLE-BOOST: отключает динамический буст и энергосбережение процессора. Не применяйте, если пользуетесь бустом на AMD/Intel. Нагрев и энергопотребление в простое вырастут.
- DISABLE-VI: отключает виртуализацию (VT-x, VT-d, AMD-V, IOMMU). Не применяйте, если пользуетесь WSL, Hyper-V, Docker, эмуляторами, виртуальными машинами или Windows Sandbox.
- DISABLE-WI-FI-N-BT: отключает Wi-Fi и Bluetooth. Не применяйте, если они вам нужны.
- AUTO-TWEAK: набор настроек, в основном под платформу AMD. Содержит параметры, которые отключают защитные механизмы и проверки (например, ECC, Write CRC, Core Watchdog Timer, обработку ошибок PCIe). Подходит не каждому и может давать нестабильность. Применяйте только после бэкапа и если готовы тестировать систему.

Частые проблемы:

Unable-To-Load-Driver (Экспорт / Импорт):
Если при экспорте или импорте ошибка "Unable To Load Driver":
1. Откройте папку Driver-Load-Fix рядом со SCEWIN-GUI и примените FIX.reg, затем перезагрузитесь и попробуйте снова (SCEWIN-GUI запускать от имени администратора).
2. Если не помогло, зайдите в Windows Security -> Device Security -> Core Isolation и отключите Memory Integrity и Microsoft Vulnerable Driver Blocklist, перезагрузитесь и повторите.

ВАЖНО про FIX.reg: он отключает Memory Integrity (HVCI), VBS, Credential Guard и список блокировки уязвимых драйверов, чтобы Windows позволил загрузить драйвер SCEWIN (amifldrv64.sys). Это снижает защиту системы. После завершения настройки BIOS верните защиту назад, применив RESET-FIX.reg из той же папки или включив эти пункты вручную в Windows Security -> Device Security -> Core Isolation, и перезагрузитесь.

Все параметры показывает как "SKIPPED" в CFGx Diagnostics:
Такое бывает, если в вашем BIOS практически нет параметров, которые можно настроить. Это никак не исправить.

Не включается ПК или возникла другая проблема после применения конфига:
Сбросьте BIOS (см. выше) и, если нужно, импортируйте сохранённый nvram.txt обратно. Затем напишите мне: ТГ: @CMEPT0HOCHbIU

Не работает Import NVRAM:
"Cannot update protected variable" - частая ошибка на материнских платах ASRock. Исправить без модификации BIOS нельзя. Если похожая ошибка на другой плате, перейдите по ссылке из диалогового окна (GitHub) и попробуйте исправить. По этой же ссылке описан моддинг BIOS. Я (xeoka) помощь с моддингом не оказываю.
