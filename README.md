# xeoka tech

**xeoka tech** — программа и набор инструментов для оптимизации **Windows 11**: меньше задержек, ровный frametime, чистая система, настройка питания, сети, драйверов и BIOS. Один интерфейс вместо десятка папок и скриптов.
Telegram автора и покупка ключа: https://t.me/CMEPT0HOCHbIU

> Все изменения вносятся на ваш риск. Перед применением создаётся точка восстановления, но сохраните свои данные.
> Некоторые настройки снижают защиту системы (отключение Defender, обновлений, VBS/HVCI, TPM/Secure Boot в BIOS).
> Работает только в Windows 11, запускается от имени администратора.

## Что умеет программа
- **Характеристики ПК на главной:** процессор, видеокарта, память, диск, сеть, версия Windows, время без перезагрузки и активный план питания.
- **Оптимизация одной кнопкой:** твики питания, процессора и системного таймера, сети, Game Bar, FSE/FSO. Можно выбрать пресет («Игровой», «Баланс», «Минимум») или отметить твики вручную. У каждого твика есть описание и метка риска, а статус («применено», «частично») показывается по реальному состоянию системы.
- **Откат:** перед применением создаётся точка восстановления, значения реестра запоминаются, кнопка «Откатить» возвращает прежнее.
- **Результат «до и после»:** замер процессов, занятой памяти, нагрузки CPU в простое, разрешения таймера, числа применённых твиков и плана питания. После перезагрузки можно нажать «Замерить сейчас» в настройках и сравнить ещё раз.
- **Инструменты:** DDU, NVCleanstall, NVIDIA Profile Inspector, CRU, Autoruns, переключатель Defender, блокировщик обновлений, службы, BIOS (SCEWIN) и другие. Опасные вещи вынесены сюда и запускаются только по отдельному подтверждению.
- **Отчёт для поддержки:** zip с журналом и сведениями о системе (без личных данных).
- **Оформление:** стеклянный интерфейс в чёрно-белом стиле с синим акцентом, тёмная, светлая и автоматическая темы, живой фон (отключается), звуки, русский и английский языки.

## Активация
Ключ покупается один раз у автора в Telegram и привязан к вашему ПК. При первом запуске показывается анимированная заставка: скопируйте ID компьютера, пришлите его автору, вставьте полученный ключ. Дальше программа открывается сразу, вводить ничего не нужно.

## Быстрый старт
1. Скачайте **XEOKA-PACK-full.zip** из [Releases](../../releases/latest) и распакуйте архив целиком (не запускайте из архива).
2. Запустите `XEOKA-PACK.exe` (запросит права администратора).
3. Введите ключ при первом запуске, выберите пресет или твики и нажмите «Оптимизировать». После завершения лучше перезагрузить ПК.

Файлы пака (инструменты, планы питания, конфиги) лежат в архиве одним зашифрованным файлом `pack.xkp`. Без действующего ключа для вашего ПК его не открыть. Программа сама находит `pack.xkp` рядом с собой, при запуске расшифровывает во временную папку и удаляет её при выходе. Если файл лежит в другом месте, укажите его в «Настройки → Пак». Отдельный `XEOKA-PACK.exe` без `pack.xkp` открывает только интерфейс.

**Требования:** Windows 11, Microsoft Edge WebView2 Runtime (в Windows 11 уже установлен). 

## Состав пака
Всё необходимое уже лежит в архиве, ничего докачивать не нужно. Приложение находит файлы по метке в корне пака и по именам внутри, а не по номерам папок, поэтому названия папок можно менять.

| Папка | Для чего | Как запускается |
|---|---|---|
| 1. База | Активация Windows, UAC, уведомления, удаление ненужных программ | Инструменты |
| 2. Драйверы | Драйвер сети (Realtek), чистка и установка драйвера NVIDIA (DDU, NVCleanstall), профиль NVIDIA Profile Inspector | Инструменты |
| 3. CRU | Разрешения и частоты монитора (Custom Resolution Utility) | Инструменты |
| 4. План-питания | План питания xeoka Performance | Оптимизация |
| 5. Геймбар-И-Игровой-Режим | Отключение Game Bar и игрового режима | Оптимизация |
| 6. Защитник-Виндовс | Переключатель Windows Defender | Инструменты |
| 7. Обновления-Windows | Блокировщик обновлений Windows | Инструменты |
| 8. Авторанс | Автозагрузка (Autoruns) | Инструменты |
| 9. Настройки-Сетевого-Адаптера | Параметры сетевой карты и её энергосбережение | Оптимизация |
| 10. Службы-И-Драйверы | Отключение служб (PowerRun) | Инструменты |
| 11. Диспетчер-Устройств | Запрет отключать устройства для экономии энергии | Оптимизация |
| 12. BIOS | Конфиги BIOS и SCEWIN (прочитайте инструкцию в папке) | Инструменты |
| 13. Аффинити | DEVICE-TWEAKER: прерывания, аффинити, USB IMOD | Инструменты |
| 14. Прерывания-Системного-Таймера | Системный таймер (SerializeTimerExpiration) | Оптимизация |
| 15. ММЦСС | MMCSS | Оптимизация |
| 16. ФСЕ-И-ФСО | Полноэкранные оптимизации: FSE и FSO | Оптимизация |
| 17. Вин-32-Приорити-Сеперейшн | Win32PrioritySeparation, приоритет активного окна | Оптимизация |

«Оптимизация» применяется кнопкой с точкой восстановления и откатом. «Инструменты» запускаются отдельно и без отката, поэтому у них есть подтверждения.

## Для разработчиков
- Исходники приложения: `app/XeokaPack` (.NET 8, WPF-окно с WebView2; интерфейс — HTML в `app/XeokaPack/Web`, логика — C# в `Core`).
- `tools/LicenseGen` — генератор ключей (в релиз не входит).
- Защита пака: сборка шифрует папки пака (AES-256-GCM) ключом, выведенным из закрытого ключа лицензий (секрет `LICENSE_PRIVATE_KEY`); каждая лицензия содержит этот ключ, зашифрованный под ID компьютера покупателя. Ключи, выданные до этого изменения, нужно выпустить заново.
- Сборка: GitHub Actions (`.github/workflows/build.yml`) на каждый пуш в `main` публикует релиз `latest` с `XEOKA-PACK.exe` и полным архивом.

## Использованные сторонние разработки
У каждой программы своя лицензия, они не входят в лицензию этого репозитория.
- Display Driver Uninstaller (DDU)
- Custom Resolution Utility (CRU), monitortests.com
- Autoruns (Sysinternals, Microsoft)
- NVCleanstall (TechPowerUp)
- NVIDIA Profile Inspector
- PowerRun
- SCEWIN / AMISCE (AMI)
- Realtek NetAdapterCx драйвер
- pci.ids (pci-ids.ucw.cz)
- **DEVICE-TWEAKER** - автор BYND_PERF (LLG), https://x.com/BEYONDPERF_LLG . Скрипт включён без изменений в содержимом, в нём сохранены ссылки автора.
- Часть скриптов и твиков (Windows Defender Switcher, Windows Update Blocker, MMCSS, сеть и др.) основана на публичных материалах сообщества Low Latency Corp (LLC).
