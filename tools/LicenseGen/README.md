# xeoka-license-gen

Генерирует коды активации для XEOKA OPTIMIZATION, привязанные к железу покупателя.

## Один раз: ключи
Закрытый ключ `private.pem` НЕ в этом репозитории — я прислал его тебе отдельно.
Положи его куда-нибудь вне репозитория (например, в свою папку с паролями) и никогда никому не показывай и не выкладывай.
Если его кто-то получит — он сможет сам генерировать рабочие лицензии для твоей программы.

## Как продать копию
1. Покупатель открывает XEOKA OPTIMIZATION, видит на экране активации свой "ID компьютера" (вида `A1B2-C3D4-...`) и присылает его тебе.
2. Ты запускаешь:
   ```
   dotnet run --project tools/LicenseGen -- --key "путь/к/private.pem" --hw A1B2-C3D4-E5F6-0000-1111 --note "Имя покупателя"
   ```
   Для лицензии на срок добавь `--days 365` (бессрочная — по умолчанию).
3. Отправляешь покупателю получившийся код (одна строка текста). Он вставляет его в окно активации.

Код работает только на том компьютере, чей ID был указан — на другом он не активируется.
